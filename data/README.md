# Data provenance

`raw/published_*.csv` contains aggregate values transcribed from Tables 1–4 of Siebers et al. (2024), DOI: 10.1177/00936502241276793. These are not individual-level records. See `raw/source_metadata.json` and the root README for details.

The MMASH dataset is documented as a separate supplementary source at https://physionet.org/content/mmash/1.0.0/. It is not downloaded or merged into this repository.
